# FusionLocks

A tiny, open-source programming language with the `.fss` file extension. This
starter release includes a Python interpreter, Windows portable launcher,
sample programs, and VS Code syntax highlighting. No third-party Python
packages are required.

## Documentation / Documentazione

- [English](README.en.md)
- [Italiano](README.it.md)

## Quick start / Avvio rapido

```text
run-fusionlocks.bat examples\hello.fss
```

Or, if Python 3 is on your PATH:

```text
python fusionlocks.py examples\hello.fss
```
